# @jvavscratch/generator

Generator module for Jvavscratch project, responsible for generating Scratch SB3 files from JavaScript code.

## Features

- SB3 project generation
- Block code generation
- Asset handling and packaging

## Installation

```bash
npm install @jvavscratch/generator
```

## Usage

```javascript
const generator = require('@jvavscratch/generator');

// Generate SB3 project
```
